Solmar Bay is an original 3D open-world crime game built with three.js (vendored), set in a sun-soaked fictional coastal city. You play Milo Kade, a driver working for the fixer Lena, taking on jobs against the rival Voss. Explore the city on foot or by car — steal any car you find — among traffic and pedestrians, while a 0–5 star wanted level brings escalating police pursuit. Three chained story missions, on-foot and driving combat, a HUD with a minimap, saves via localStorage, and synthesized WebAudio sound and music round out the experience. It runs offline from static files in a desktop browser. Controls: WASD move/drive, E enter/exit car, F punch, CLICK shoot, SHIFT run, P pause, M mute.

## Run it

```sh
node serve.ts
http://localhost:8080
```
